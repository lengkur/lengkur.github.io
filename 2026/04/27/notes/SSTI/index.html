tornado.web.RequestHandler._template_loaders

这在tornado中是一个模板加载器，是一个私有字典，tornado用这个实现了懒加载机制，就跟前面说的一样，tornado只会把模板渲染一次，一次之后，如果不重启或把字典中对应的模板清空，是不会再加载的

当然，如handler.settings中有设置**”debug”:true**，会默认禁用这种缓存机制

这时候就危险得多，现实中很少这种情况，如果这个字典可以控制，我们也可以用他来读取文件

特性

字典键值覆盖

原理

模板引擎在底层有解析和渲染阶段

在底层有一个叫named_blocks的字典，这字典用来存储区块block对应的信息，block是具有唯一性的

解析阶段

引擎读到第一个 {% block name %}a{% end %}，把区块存入字典：blocks = {“name”: “a”}

引擎紧接着读到第二个 {% block name %}b{% end %}，由于字典的键（Key）必须是唯一的，后面的 “name” 会直接把前面的 “name” 覆盖掉。

此时，内部字典变成了：blocks = {“name”: “b”}

渲染阶段

引擎走到第一个区块的原始位置，去字典里查找名叫 name 的内容。字典里现在的记录是 “b”，于是输出 b。

引擎走到第二个区块的原始位置，再次去字典里查找名叫 name 的内容。字典里的记录依然是 “b”，于是再次输出 b，就形成了bb

我们可以利用模板覆盖这一特性，可以用来获取一些信息和执行一些命令
